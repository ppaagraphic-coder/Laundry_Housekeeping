# ระบบติดตามผ้าซัก — inchantree meedao

เว็บแอปสำหรับบันทึกการส่ง-รับผ้ากับร้านซัก พร้อมลายเซ็น ฟอร์ม PDF ตามแบบเดิมของโรงแรม และแจ้ง Admin ทุกขั้นตอน
หน้าเว็บ deploy บน **GitHub Pages** ส่วนข้อมูลและ log เก็บใน **Google Sheet** (ผ่าน Google Apps Script)

## ใครใช้ทำอะไร

| ผู้ใช้ | เข้าด้วย | ทำอะไร |
|---|---|---|
| หัวหน้าแม่บ้าน | PIN | **เก็บผ้ารายวัน** (เซ็นทุกครั้ง) → **ส่งซัก** (รวมยอดสะสมเป็นใบส่งผ้า) → รับผ้าคืน ตกลงยอดกับร้าน |
| Admin | PIN | ดูภาพรวม ผ้าสะสมรอส่ง ผ้าค้างที่ร้าน เทียบสต็อก (par) แก้ไข/ยกเลิกเอกสาร (ต้องใส่เหตุผล) ตั้งค่า |
| ร้านซัก (หลายร้าน) | ลิงก์เฉพาะใบ `?t=...` | นับผ้า เซ็นรับ รับทราบใบแจ้งผ้าขาด (ไม่ต้องล็อกอิน) |

## Workflow

```
ขั้นที่ 1  เก็บผ้ารายวัน (หลังแขกเช็คเอาท์ หรือสรุปรายวัน) → กรอกจำนวนแยกชั้น → เซ็น → ได้ใบรายงานเก็บผ้า (PDF) + แจ้ง Admin
           ผ้าไปสะสมสถานะ "รอส่งซัก" (ยังไม่มีกำหนดส่งตายตัว สะสมกี่วันก็ได้)
ขั้นที่ 2  ส่งซัก → ระบบรวมยอดจากใบเก็บผ้าที่สะสมไว้ทั้งหมดลงใบส่งผ้าให้อัตโนมัติ (เลือกเอาใบไหนออกได้)
           นับของจริงก่อนส่ง แก้ตัวเลขได้ → แถวที่ต่างจากยอดสะสมขึ้นสีแดง + แจ้ง Admin
           → เซ็นส่ง → ส่งลิงก์ให้ร้านซัก
      → ร้านนับ+เซ็น  ── ตรง ──→ ร้านรับผ้าแล้ว
                       └─ ไม่ตรง → แม่บ้านตกลงยอด (บันทึกเหตุผล)
      → รับผ้าคืน นับเทียบยอดส่ง ── ครบ ──→ ปิดงาน
                                  └─ ขาด/ชำรุด → ออกใบแจ้ง (ลิงก์เดิม) → ร้านรับทราบ
                                        → รับผ้าที่ขาดเพิ่ม → ครบแล้วปิดงานอัตโนมัติ
```

ทุกขั้นตอนมีอีเมลแจ้ง Admin และบันทึกใน Log เอกสารที่เซ็นแล้วแก้ไขไม่ได้ ยกเว้น Admin ซึ่งต้องใส่เหตุผลและระบบเก็บค่าก่อน/หลังทุกครั้ง

## โครงสร้างโฟลเดอร์

```
index.html, css/, js/, assets/   หน้าเว็บ (ขึ้น GitHub Pages)
js/config.js                     ใส่ URL ของ Apps Script ที่นี่ที่เดียว
js/core.js                       ตรรกะหลัก (ใช้ทั้งโหมดทดลองและ Apps Script)
apps-script/                     โค้ดฝั่ง Google Sheet (Code.gs, Core.gs, appsscript.json)
tests/                           ชุดทดสอบ (node tests/flow.test.js, node tests/gas-harness.test.js)
tools/sync-core.sh               คัดลอก js/core.js → apps-script/Core.gs หลังแก้ตรรกะ
```

## ลองก่อน (โหมดทดลอง)

เปิด `index.html` ผ่านเว็บเซิร์ฟเวอร์ (เช่น `python3 -m http.server`) ถ้า `API_URL` ใน `js/config.js` ว่างอยู่ ระบบจะเก็บข้อมูลในเบราว์เซอร์เครื่องนั้น
PIN ทดลอง: หัวหน้าแม่บ้าน `222222`, Admin `111111`

## ติดตั้งใช้งานจริง

### 1) ตั้ง Google Sheet + Apps Script (ประมาณ 10 นาที)

1. สร้าง Google Sheet ใหม่ (ตั้งชื่ออะไรก็ได้ เช่น "ผ้าซัก - ฐานข้อมูล")
2. เมนู **Extensions → Apps Script**
3. สร้างไฟล์ในโปรเจ็กต์ให้ตรงกับในโฟลเดอร์ `apps-script/`
   - `Code.gs` วางเนื้อหาจากไฟล์ `Code.gs`
   - สร้างไฟล์ใหม่ชื่อ `Core` (จะได้ `Core.gs`) วางเนื้อหาจากไฟล์ `Core.gs`
   - เปิด Project Settings → ติ๊ก "Show appsscript.json manifest file" แล้ววางเนื้อหาจาก `appsscript.json`
4. เลือกฟังก์ชัน **`setup`** แล้วกด Run (ครั้งแรกจะขอสิทธิ์ ให้อนุญาต) ระบบจะสร้างแท็บทั้งหมด หัวตาราง รายการผ้า 19 รายการ และตั้งเวลาเตือนผ้าค้างทุกเช้า 08:00
5. เปิดแท็บ **Users** จดหรือเปลี่ยน PIN ของ Admin และหัวหน้าแม่บ้าน (ค่าเริ่มต้นสุ่มให้ตอนรัน setup)
6. **Deploy → New deployment → Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - กด Deploy แล้วคัดลอก URL ที่ลงท้ายด้วย `/exec`

> **อัปเดตจากเวอร์ชันก่อนหน้า (v1.0 → v1.1):** วาง `Core.gs` และ `Code.gs` ใหม่ → รัน `setup()` อีกครั้ง (จะเพิ่มแท็บ Collections / CollectionLines และคอลัมน์ใหม่ใน Slips / SlipLines โดยไม่ลบข้อมูลเดิม ไม่สุ่ม PIN ใหม่) → Deploy เวอร์ชันใหม่

> ทุกครั้งที่แก้โค้ดใน Apps Script ต้อง Deploy → Manage deployments → Edit → New version เพื่อให้มีผล

### 2) ตั้งค่าหน้าเว็บและขึ้น GitHub Pages

1. แก้ `js/config.js` ใส่ URL ที่ได้: `API_URL: 'https://script.google.com/macros/s/.../exec'`
2. สร้าง repository บน GitHub แล้ว push ไฟล์ทั้งโฟลเดอร์ (ไม่ต้อง push `apps-script/` และ `tests/` ก็ได้)
3. Settings → Pages → Source: เลือก branch `main` โฟลเดอร์ `/ (root)`
4. ได้ที่อยู่เว็บ เช่น `https://ชื่อคุณ.github.io/ชื่อโปรเจ็กต์/`

### 3) ตั้งค่าในระบบ

เข้าสู่ระบบเป็น Admin → **ตั้งค่า / สต็อก**
- ใส่ **อีเมล Admin** (รับแจ้งทุกขั้นตอน + สรุปผ้าค้างทุกเช้า) และ **ที่อยู่เว็บแอป** (ใส่ลิงก์ในอีเมล)
- เพิ่ม/แก้ร้านซัก (ใส่อีเมลร้านถ้าต้องการให้ระบบส่งลิงก์ให้ร้านอัตโนมัติ ถ้าไม่ใส่ แม่บ้านกด "คัดลอก/แชร์ลิงก์" ส่งเอง เช่น ทาง LINE ส่วนตัว)
- กรอก **สต็อกมาตรฐาน (par)** ของแต่ละรายการ

## รายงานสรุป (Admin) — v1.2

เมนู **รายงานสรุป** มี 3 แท็บ เลือกวัน/เดือน/ปีได้ด้วยปุ่ม ‹ ›

| แท็บ | แสดงอะไร |
|---|---|
| รายวัน | ผ้าแต่ละชนิดต่อวัน: เก็บผ้า / ส่งซัก / รับคืน / ขาด / ชำรุด, จำนวนครั้งส่งซักและรับคืน, ข้อผิดพลาดที่เกิดขึ้น |
| รายเดือน | เหมือนรายวันแต่ต่อเดือน + ยอดสะสมตั้งแต่ 1 ม.ค. ถึงสิ้นเดือน (YTD) + ตารางรายวันพร้อมยอดสะสม (กดดูรายวันได้) |
| รายปี | ต่อปี + ตารางรายเดือนพร้อมยอดสะสมของปี (กดดูรายเดือนได้) |

- ดาวน์โหลด CSV ได้ทุกแท็บ และซ่อนรายการที่ไม่มีความเคลื่อนไหวได้
- **ข้อผิดพลาด 8 ประเภท:** ร้านนับยอดไม่ตรง, ผ้าขาดตอนรับคืน, ผ้าชำรุด/คราบ, รับคืนเกินที่ส่ง, ยอดส่งต่างจากยอดสะสม, Admin แก้ไขเอกสาร, ยกเลิกเอกสาร, ปิดงานโดยตัดยอดผ้าขาด
- ผ้าขาดนับ ณ วันที่พบครั้งแรก (ใบแจ้งขาดฉบับแรก) เพื่อไม่นับซ้ำเมื่อออกใบแจ้งฉบับใหม่
- อัปเกรดจาก v1.1: ไม่มีการเปลี่ยนโครงสร้างชีต เพียงวาง Core.gs และ Code.gs ใหม่ แล้ว Deploy → New version

## แท็บใน Google Sheet

| แท็บ | เก็บอะไร |
|---|---|
| Collections / CollectionLines | ใบเก็บผ้ารายวัน (สถานะ รอส่ง / ส่งแล้ว / ยกเลิก) |
| Slips / SlipLines | ใบส่งผ้าและรายการผ้า (แยกตามชั้น) พร้อมยอดสะสมจากใบเก็บผ้าไว้เทียบ |
| Receipts / ReceiptLines | การรับผ้าคืนแต่ละครั้ง |
| Shortages / ShortageLines | ใบแจ้งผ้าขาด/ชำรุด |
| Signatures | ลายเซ็น (รูป PNG) ทุกครั้งที่เซ็น |
| Revisions | ประวัติการแก้ไขโดย Admin / ตกลงยอด / ตัดยอด (ค่าก่อน→หลัง + เหตุผล) |
| Log | ทุกเหตุการณ์ ใครทำอะไรเมื่อไร (ใช้มอนิเตอร์ / ทำ Pivot ได้) |
| Items, Vendors, Users, Config | ข้อมูลหลัก (เพิ่ม/เปลี่ยนชื่อรายการผ้าได้ที่แท็บ Items) |

**อย่าแก้ข้อมูลในแท็บ Slips / Log ตรงๆ** ถ้าต้องแก้ให้ใช้หน้า Admin เพื่อให้มีประวัติ (ตัวอย่าง: การแก้ในชีตตรงๆ จะไม่มีเหตุผลและไม่แจ้งใคร)

## PDF

เปิดใบส่งผ้า → **เปิดเอกสาร / บันทึกเป็น PDF** → กดพิมพ์ แล้วเลือก "บันทึกเป็น PDF" (A4 แนวนอน)
ชุดเอกสารมีสูงสุด 3 หน้า: ใบส่งผ้า (ตามแบบเดิม + อ้างอิงใบเก็บผ้า) · ใบตรวจรับผ้าคืน · ใบแจ้งผ้าขาด/ชำรุด พร้อมลายเซ็นและหัวกระดาษโรงแรม
ใบเก็บผ้ารายวันเปิดได้จากหน้าใบเก็บผ้าแต่ละใบ (รายงานเก็บผ้ารายวัน 1 หน้า พร้อมลายเซ็นผู้เก็บ)

## ข้อจำกัดที่ควรรู้ (MVP)

- **ความปลอดภัย:** PIN เก็บเป็นข้อความธรรมดาในแท็บ Users และใครมีลิงก์ร้านซักก็เปิดใบนั้นได้ จึงควรให้เฉพาะคนที่ควรเห็น เอกสารมีลายเซ็นและข้อมูลภายใน
- **โควตา Google:** อีเมลจาก Apps Script ส่งได้ราว 100 ฉบับ/วัน (บัญชีทั่วไป) เพียงพอกับงานระดับ 40 ห้อง
- **ความเร็ว:** Google Sheet ตอบช้าราว 1-3 วินาทีต่อการกด ถ้าเอกสารสะสมหลายพันใบควรสำรองและย้ายข้อมูลเก่าไปไฟล์อื่น
- **ไม่มีการแจ้งเตือน LINE** ตามที่ตกลง (ใช้อีเมลแทน)
- ใบเก็บผ้ากรอกเป็น "จำนวนต่อชั้น" (5 ชั้น + วิลล่า) และมีช่อง "ห้องที่เก็บ" เป็นข้อความอิสระ ยังไม่ได้แยกจำนวนรายห้อง ถ้าต้องการติดตามรายห้องค่อยเพิ่มได้
- ใบเก็บผ้าที่เซ็นแล้วแก้ไม่ได้ ถ้าผิดให้ Admin แก้ (พร้อมเหตุผล) ก่อนถูกรวมในใบส่งผ้า หลังส่งซักแล้วให้แก้ที่ใบส่งผ้า ถ้ายกเลิกใบส่งผ้า ใบเก็บผ้าจะกลับมารอส่งซักให้เอง
- ฟอนต์ใช้ Anuphan จาก Google Fonts ถ้าออฟไลน์จะใช้ฟอนต์ไทยของเครื่องแทน
